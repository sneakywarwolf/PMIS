PMIS-Project Management for Information Security

A self-hosted, role-based web application for Vulnerability Assessment & Penetration Testing (VAPT) teams: engagements, findings, evidence, a shared vulnerability library and generated Word or Excel reports in one place.

What PMIS does

Engagements

Projects for Web, API, Mobile, Thick Client and Network assessments under VAPT, PCI, CERT-In or ASV, each with a tester and a Team Lead.

Findings and evidence

Findings drawn from a shared vulnerability library, with affected assets, CVSS overrides and numbered proof-of-concept steps with one or more screenshots each. Add a finding by hand or import many from CSV or Excel when it is not in the library.

Scan imports

Nessus results, Nmap port scans and network scope lists imported straight into Network projects.

Vulnerability library

One curated library with an approval workflow, so finding wording stays consistent across reports.

Report generation

Word and Excel reports filled from your own templates, plus an Issue Log export.

Team oversight

Dashboards, notifications, live-user view, project change history and a retention tracker.

Getting started

  1. Install PMIS with Docker Compose.
  2. Sign in as admin, set a new password, create your users and upload your report templates.
  3. Before anyone else uses it, put it behind HTTPS and work through the production checklist.
