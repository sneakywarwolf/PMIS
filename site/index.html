PMIS-Project Management for Information Security

A web-based RBAC project management and dynamic report generation system for Vulnerability Assessment & Penetration Testing (VAPT) teams.

GitHub repository MIT License Changelog 1.0.0

Overview

PMIS tracks VAPT engagements from project setup through scoping, findings, proof-of-concept evidence, vulnerability approval and generated Word or Excel reports. Access is role-based: Admins, AVPs, Team Leads and Testers see the projects and data their role and team allow.

Capabilities

  • Projects: client, scope, dates, compliance type, testing environment, and category and sub-type (Web, API, Mobile, Thick Client, Network, Application). Team Leads and Admins can reassign testers. Status moves through Not started, In progress, Awaiting review and Completed.
  • Findings and PoC: attach catalogue vulnerabilities to a project, record affected instances and authentication type, override CVSS score and vector, and document ordered PoC steps with images (PNG, JPG, GIF, WebP).
  • Vulnerability catalogue: shared list with search, severity filters, CSV export and an approval workflow for new entries. Testers propose edits to approved entries as change requests.
  • Scan imports: Nessus (.nessus or .csv) with per-plugin selection, and Nmap XML for Network projects. Imported records belong to the project and are not added to the shared catalogue.
  • Reports: Admin-uploaded Word or Excel templates with highlighted placeholders, queued generation, a preflight check for missing data, an Issue Log CSV, and signed, expiring download links.
  • Dashboards, notifications and retention: team and organisation views, an activity feed, in-app notifications, and a retention countdown for completed projects.
  • Engagement features: a daily security quiz with a leaderboard, and a separate "Pattern Map" game whose scores do not affect quiz points.
  • Administration: user management with CSV or XLSX bulk upload, admin-configurable settings with change history, system health, scheduled updates and audit logging.
