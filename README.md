# PMIS-Project Management for Information Security

A web-based RBAC project management and dynamic report generation system for Vulnerability Assessment & Penetration Testing (VAPT) teams.

**Documentation site:** https://sneakywarwolf.github.io/PMIS/ (source in [`site/`](site/))

> PMIS is for **authorized** security testing only. Operators are responsible for lawful use and for protecting the client and vulnerability data they store in it.

## Repository layout

| Path | Contents |
|---|---|
| `apps/backend/` | NestJS API and Prisma schema |
| `apps/frontend/` | Next.js web UI |
| `docker-compose.yml` | Production-style stack |
| `docker-compose.dev.yml` | Local infrastructure for running the apps with npm |
| `docs/` | Design and security review documents |
| `site/` | GitHub Pages documentation |
