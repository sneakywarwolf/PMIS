# Contributing

1. Fork, create a branch from `master`, open a PR describing the change.
2. Set up the dev environment as in the README ("Option B").
3. Run the tests before opening the PR: `cd apps/backend && npm test` (and `npm test` in `apps/frontend` if you touched it).
4. Keep PRs focused; match the surrounding code style (`npm run lint`).
5. Never commit `.env`, logs, client data or real report files.

Security issues: see [SECURITY.md](SECURITY.md), not public issues.
Be respectful: this project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
